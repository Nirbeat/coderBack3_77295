VACÍA, CON UN SO LINUX Y NODE SOLAMENTE

EL SERVIDOR TENDRA UN UNICO ENDPOINT QUE DEVOLVERA EL RESULTADO
DE UNA DIVISIÓN DE NÚMEROS, ERROR SI SE DIVIDE POR CERO

1-CONFIGURAMOS EL SERVER MINIMO CON SU ESTRUCTURA DE ARCHIVOS
2-CREAMOS UN TEST PARA LA FUNCION DE DIVISION
3-CREAMOS LA FUNCION DE DIVISION A PARTIR DE LOS TEST Y TESTEAMOS
4-IMPLEMENTAMOS LA FUNCION EN EL ENDPOINT
5-PROBAMOS CON SUPERTEST

CREAR DOCKERFILE DE NUESTRA APP

CREAR IMAGEN
docker build -t comision-77295 .

CORRER IMAGEN CON DOCKER, LA FLAG -e ES PARA VARIABLES DE ENTORNO
docker run -d -p 3000:3000 --name integrador -e PORT=3000 comision-77295

EXPONER LA MAQUINA A INTERNET
npx localtunnel --port 3000

CREAR ARCHIVOS PARA CI-CD CON GITHUB ACTIONS

    -modificar script de test por "test": "npx mocha test/server.test.js",
    -.github/workflows/deply.yml
name: Pipeline Integral CI/CD
on:
  push:
    branches: [ ci-cd ] # Se ejecuta cuando hacés push a main

jobs:
  pipeline-completo:
    runs-on: ubuntu-latest # Corre en la nube de GitHub
    steps:
      # ==========================================
      # PARTE 1: CI (INTEGRACIÓN CONTINUA)
      # ==========================================
      - name: 1. Descargar el código de GitHub
        uses: actions/checkout@v4

      - name: 2. Instalar Node.js en la nube
        uses: actions/setup-node@v4
        with:
          node-version: 20

      - name: 3. Instalar dependencias del Test
        run: npm install

      - name: 4. Ejecutar los Tests contra mi Docker Local
        run: npm test
        env:
          SERVER_URL: "https://slimy-rooms-press.loca.lt"

      # ==========================================
      # PARTE 2: CD (DESPLIEGUE CONTINUO)
      # ==========================================
      # - name: 5. Disparar el Despliegue en el Contenedor
      #   # Este comando solo se ejecuta si el paso 4 (los tests) dio VERDE
      #   run: |
      #     curl -X POST "https://slimy-rooms-press.loca.lt/deploy"
